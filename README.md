# DeathClient 1.8.8 全汉化版

[English](./README_EN.md) | 简体中文

EaglerX 1.8.8 网页版 Minecraft 作弊客户端的深度汉化版本。

## 简介

这是 **DeathClient 1.8.8** 的中文汉化版，将作弊客户端的所有界面文本尽可能地翻译成了中文，方便国内玩家使用。

## 特点

- ✅ **作弊模块全部汉化**（约40+个模块名称）
- ✅ **模块描述全部汉化**（约20条）
- ✅ **界面元素全部汉化**（分类、标签、按钮等）
- ✅ **虚拟按键界面全中文**
- ✅ **默认语言已设置为中文**
- ✅ **性能优化**（自动降低渲染距离、关闭特效）

## 已汉化内容

### 作弊模块

**移动类：** 飞行、速度、兔子跳、自动台阶、安全行走、无减速、水上行走、远距离跳、无跳跃延迟、跑酷、背包移动、目标环绕

**渲染类：** 透视、玩家透视、物品透视、方块透视、自由视角、帧率提升、全亮、碰撞箱、高亮信息、面包屑导航、TNT计时器

**玩家类：** 自动瞄准、自动点击器、作弊检测器、鼠标修复、自动F5、禁用动态视野

**战斗类：** 杀戮光环、暴击、击退、攻击距离

**HUD类：** 按键显示、坐标显示、护甲显示、名牌、弹道

### 界面元素

- 左侧分类名：移动、渲染、玩家、战斗、世界、界面
- 底部标签：插件、配置文件、路径点、建筑蓝图、设置
- 披风界面：名称、状态、按钮
- 登录界面：用户名、密码、注册、访客模式
- 虚拟按键界面：全部中文

## 未汉化部分

- 游戏本身的主菜单、设置界面（这些文本打包在EPK资源文件里，无法直接修改）
- 部分动态生成的文本

## 使用方法

1. 下载 `DeathClient-1.8.8-zh.html` 文件
2. 用浏览器（Chrome/Edge/Firefox）打开
3. 直接游玩，所有作弊客户端界面都是中文的

## 性能优化

本版本已内置性能优化，自动设置：
- 渲染距离：2区块（最低）
- 粒子效果：关闭
- 云朵：关闭
- 垂直同步：关闭
- FPS限制：30

如果还是卡，可以在游戏设置里手动调低设置。

## 已知问题

- 游戏本身的界面（主菜单、选项等）还是英文的
- 可能会有个别模块名称还是英文的
- 默认语言已设置为中文（zh_CN），但语言包不完整
