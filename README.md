# DeathClient 1.8.8 中文汉化版

[English](./README_EN.md) | 简体中文

EaglerX 1.8.8 网页版 Minecraft 作弊客户端的中文汉化版本。

## 简介

这是 **DeathClient 1.8.8** 的中文汉化版，将作弊客户端的模块名称、界面元素等翻译成了中文，方便国内玩家使用。

### 最新版本：v1.4.3 (1.8.8, beta)

---

## 特点

- **作弊模块名称汉化**（约50+个模块）
- **主菜单界面汉化**（单人游戏、多人游戏、选项等）
- **按钮汉化**（完成、取消、返回、确定等）
- **设置选项汉化**（主题色、警报音效等）
- **无需下载安装**，浏览器直接运行

---

## 已汉化内容

### 主菜单
- 单人游戏（Singleplayer）
- 多人游戏（Multiplayer）
- 选项（Options）

### 按钮
- 完成（Done）
- 取消（Cancel）
- 返回（Back）
- 是（Yes）
- 否（No）
- 确定（OK）

### 作弊模块
**自动类：** 自动瞄准、自动穿甲、自动攻击、自动点击器、自动关闭、自动检测、自动钓鱼、自动跳跃、自动离开、自动药水

**防类：** 防挂机、防失明、防仙人掌、防火球、防受击

**其他：** 飞行、速度、自由视角、快速破坏、快速放置、跑酷、背包移动、护甲显示、空中攻击

---

## 使用方法

1. 下载整个项目
2. 用浏览器打开 `client/versions/1.8/1.4.3/js/index.html`
3. 开始游玩
