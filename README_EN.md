# DeathClient 1.8.8 Full Chinese Localization

简体中文 | [English](./README.md)

Deeply localized Chinese version of DeathClient 1.8.8 for EaglerX 1.8.8 web-based Minecraft.

## Introduction

This is the Chinese localization of **DeathClient 1.8.8**, with all cheat client interface text translated to Chinese for Chinese-speaking players.

## Features

- ✅ **All cheat modules translated** (40+ module names)
- ✅ **All module descriptions translated** (20+ descriptions)
- ✅ **All UI elements translated** (categories, tabs, buttons, etc.)
- ✅ **Virtual keyboard interface fully Chinese**
- ✅ **Default language set to Chinese**
- ✅ **Performance optimization** (auto reduced render distance, disabled effects)

## Translated Content

### Cheat Modules

**Movement:** Fly, Speed, Bunny Hop, Auto Step, Safe Walk, No Slow, Water Walk, Long Jump, No Jump Delay, Parkour, InventoryMove, Target Strafe

**Render:** ESP, Player ESP, Item ESP, Block ESP, FreeCam, FPS Boost, Full Bright, Hitboxes, WAILA, Breadcrumbs, TNT Timer

**Player:** Aimbot, Auto Clicker, Cheater Sniffer, Mouse Fix, Auto F5, No Dynamic FOV

**Combat:** Kill Aura, Criticals, Velocity, Reach

**HUD:** Keystrokes, Coords, Armor HUD, Nametags, Trajectories

### UI Elements

- Left categories: Movement, Render, Player, Combat, World, Hud
- Bottom tabs: Plugins, Profiles, Waypoints, Schematics, Settings
- Cape interface: names, status, buttons
- Login interface: username, password, sign up, guest mode
- Virtual keyboard: fully Chinese

## Not Translated

- Game's main menu and settings interface (text is packed in EPK resource files, cannot be directly modified)
- Some dynamically generated text

## Usage

1. Download `DeathClient-1.8.8-zh.html`
2. Open with browser (Chrome/Edge/Firefox)
3. Play directly - all cheat client interfaces are in Chinese

## Performance Optimization

This version includes built-in performance optimization with automatic settings:
- Render distance: 2 chunks (minimum)
- Particles: disabled
- Clouds: disabled
- VSync: disabled
- FPS limit: 30

If still laggy, you can manually lower settings in game options.

## Known Issues

- Game's main menu and options are still in English
- Some module names may still be in English
- Default language set to zh_CN, but language pack is incomplete
